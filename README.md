# Customer Churn Prediction

Predicts which subscription customers are likely to leave, ranks them by risk, and suggests review reasons and retention actions. Built with Python, scikit-learn, XGBoost and Streamlit.

> The dataset is **synthetic** (generated by `src/generate_data.py`), so there is no confidential data in this repo.

## Live demo
Deployed on Streamlit Community Cloud: https://customer-churn-prediction-zedpba8tn3grzuydusuxxn.streamlit.app/

Project Report: _https://github.com/Puneeth7104/Customer-Churn-Prediction/blob/main/Customer_Churn_Project_Report.pdf_

## Pipeline
1. **Data** - 5,000 synthetic customers: demographics, tenure, usage (3 months), support interactions, billing history, churn label (~30%).
2. **Cleaning** - median imputation for missing values, one-hot encoding, outlier capping, class-imbalance handling (class weights / `scale_pos_weight`).
3. **Features** - usage trend, 3-month average usage, support-contact frequency, price change %, charges per tenure, low-engagement flag, payment-risk flag.
4. **Models** - Logistic Regression (baseline), Random Forest, XGBoost.
5. **Evaluation** - ROC-AUC, precision, recall, F1, Brier score, calibration curve.
6. **Deployment** - Streamlit app + ranked high-risk list with reasons (`outputs/ranked_high_risk_customers.csv`).

## Run locally
```bash
pip install -r requirements.txt
python src/generate_data.py      # creates data/customer_data.csv
python -m src.train              # trains models, saves models/ and outputs/
streamlit run app.py
```
